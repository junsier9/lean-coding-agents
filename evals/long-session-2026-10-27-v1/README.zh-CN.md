# 原生 Codex 长会话环境诊断

这是登记下一轮已知契约复核前的运行环境检查，不是 skill 有效性、泛化或效率样本。候选、已知维护题和 13 道保留新题均不参与本诊断。原 v4/v5/v6 及 11/12 环境窗口失败保持原样。

首次模型调用前在本机冻结了 [协议](protocol.json)、驱动、探针、原生二进制、原模型配置、完整代理/MXC 配置和旧失败摘要。固定最多六个原生会话，分两批、每批三个并发；每个会话须完成十二次独立模型/shell 往返，并持续至少 300 秒、最多 600 秒。每步等待 25 秒，后续步骤必须使用前一实际工具输出的令牌。不能批量合并成一次工具调用。

六个会话必须全部正常结束、完整计量、无请求重连/容量错误、无失败工具、令牌与实际磁盘输出一致且源文件不变。第一批任何失败即停止第二批；所有六个计划位置保留，不运行的位置也不能通过。窗口内不补跑或替换失败。

预检查使用真实 MXC 执行器验证正确步骤可运行、错误令牌会被拒绝；另用明确标识的合成日志验证成功、重连错误和缺失步骤三种判定。预检查没有模型调用，不能作为六个原生会话之一。

本诊断只覆盖 shell 与模型的多轮会话，不等于单条 SSE 连接连续五分钟，也不证明未来可用率或工业级 SLA。元数据、插件和 MCP 启动警告另作实际 stderr 观察，不将其隐去或宣称相关功能已获验证。下一轮十二次真实维护契约仍须单独通过；本次请求仅登记该轮，不执行它，更不启用新题。

实际结果：六个会话全部通过，每个完成 12 轮，共 72 次独立工具往返。单会话时长 385.2–419.9 秒，正常结束和完整 usage 均为 6/6；模型请求重连、容量错误和失败工具均为 0。见[完整结果](results/summary.json)和[私有证据归档清单](results/evidence-retention.json)。

[元数据与 MCP/插件启动观察](results/startup-observations.json)仍记录实际超时/失败警告，因此只将本轮结果用作 shell 长会话登记门槛，不宣称整个平台功能稳定。随后[下一轮 12 次已知契约环境复核](../environment-revalidation-2026-10-27-v2/README.zh-CN.md)已完成准备和输入冻结；该轮原生维护调用仍为 0，新题未启用。
