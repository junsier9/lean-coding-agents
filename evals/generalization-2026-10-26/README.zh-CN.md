# v5 未参与修订任务的前瞻质量验证

本批次只评估能否以测试版分发，不重新开启已经关闭的稳定提速确认性检验。用户选择公开 GitHub、原创内容 MIT、免费 Agensi；质量达标但效率未证实时明确标注 beta。

## 冻结设计

候选规则与 UI 元数据逐字复制已完成开发的 v5，SHA256 分别为 `87339E154142B56E3836D3A5DB28A198F686945CA30A1DA7FEDD248E5A521256` 和 `E786C393174A36E6CAD32DD46325844B3036FC65619117984EBA926A93274E1A`。规则、任务顺序、门槛、观察器和驱动均在本批原生模型调用前冻结；见 [协议](protocol.json)、[冻结清单](results/freeze.json)与[冻结时间](results/frozen-at.json)。

从此前固定并完成契约审查的 `remaining_adequate` 列表中，按原顺序取前 20 题，每题 3 次。冻结时检查历史运行记录中的题目 ID、修复提交与去掉查询参数的来源 URL 不重叠。另复测 12 个已知关键错误处理契约，每题 1 次，并以普通与 `-O` 模式评分；这些任务只算已知回归，不算新泛化证据。

共计划 72 次，最多 3 个原生 Codex 客户端并发，同一 `gpt-6.1-sol / xhigh` 配置；不设无 skill 对照，因此不能估计 skill 的因果收益或比较速度、token。保留所有超时、失败和缺失计量，不替换失败的模型尝试。已完成客户端只允许有记录的评分恢复。

测试版门槛：60 次新题至少通过 57 次、每题至少 2/3；12 个已知关键契约全部通过；72 次正常结束且实际工具输出包含完整规则正文；预先指定的 8 份产物独立审查均无确认的危险回归或无当前理由的机制；来源、轨迹、证据与安装包验证通过。达到这些条件也不等于工业级生产资格。

独立审查收到原任务、初始源码和候选产物；不收到 skill、参考修复、隐藏评分器、模型成绩、耗时、token 或父代理结论。8 份产物来自协议预选的任务位置与第 0 次重复，不能按结果更换。

## 观察与复跑

`observe.py` 只从已完成工具的实际返回值寻找完整正文，支持 shell、MCP 文本/嵌套 JSON、非执行的字符串字面量拼接解码；不把调用参数或代理自述算作读取证据。[观察器检查](results/observer-preflight.json)复核 6 份已有开发日志和 8 个正反探针；该检查没有新模型调用，也不增加泛化样本。

在保留私有源归档、依赖和本机解释器的原环境中：

```powershell
python -B evals/generalization-2026-10-26/run.py --prepare-only
python -u -B evals/generalization-2026-10-26/run.py
```

解释器须为冻结清单指定的 Python 3.12.14，命令中的 `python` 仅为简写。脚本复用原有本机归档，不负责安装依赖或配置账户。旧 v4 评分器、规则和报告不修改，完成记录复用，不重复付费运行。公开源码不是独立环境的一键全量重建器。

## 解释边界

新题来自先前做过源码契约审查、但没有原生解题记录且未用于 v5 修订的保留集，仍来自已有项目。题目不同不能证明统计独立、训练语料无污染或新仓库泛化。已知关键契约和已揭露开发任务分别报告。Claude 没有验证。旧 v4 生产资格失败和未证明稳定效率收益的结论完整保留。

## 最终结果

本批已完成 72 次原生尝试，没有补跑或替换失败。新题契约通过 59/60（98.3%），每题至少 2/3；已知关键错误边界 12/12，普通及 `-O` 模式均通过。完整规则输出 72/72；正常成功终止 70/72，完整 usage 70/72。一次 600 秒超时留下的补丁通过了契约测试；另一次模型容量错误的补丁未通过，原错误与两个缺失计量完整保留。

8 份预选产物的独立审查发现 2 项兼容回归：新增比较破坏了原来合法的 `__index__` 整数边界对象；新增可选签名探测遇到非标准 `Exception` 时破坏原有可调用对象兼容。父代理独立复现两项初始成功、候选失败。后一项保留中等置信度及自定义签名属性的有限适用范围，不能扩张成普遍故障或安全漏洞。

因此[测试版完整资格裁决](results/beta-qualification.json)为 **false**，失败门槛是原生会话全部正常结束及独立审查无确认缺陷。通过率较高不能覆盖审查发现，也不证明 skill 的因果收益。**v5 不上架为可用测试版**，旧 v4 失败结论不变。
