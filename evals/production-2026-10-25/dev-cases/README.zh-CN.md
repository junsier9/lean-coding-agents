8 个独立 Python 标准库合成任务，覆盖不可变验证管道、混合绕过路径、配置所有权、边界错误翻译、幂等重试、SQLite 原子事务、异步取消和可变插件回调。每题包含 2–3 个初始源码文件、明确中文任务、参考源码覆盖和隐藏 unittest。

捆绑 Python 3.12.14 上已实跑：8 个初始版本均被拒绝，8 个参考版本的 95 个测试方法全部通过；每题 11–15 个方法，另含输入子例。结果见 `preflight.json`，原始输出在 `preflight/`。`manifest.json` 保存每份题目 JSON 的 SHA256。

执行代理只能获得 JSON 的 `files` 与 `task`；不得提供 `reference_files`、`hidden_tests` 或本目录的评分日志。评分时用候选源码覆盖初始源码，再独立恢复隐藏测试；不得让候选测试替代验收。

生成与预筛：

```powershell
python -B evals/production-2026-10-25/dev-cases/build_cases.py
```

`python` 应指 Python 3.12；脚本不调用模型或网络。预筛源码写入本目录中的独立临时目录，测试后自动清理。
