## 构建与使用

在仓库根目录运行 `python releases/0.7.1-beta.1/build.py`，生成 `dist/lean-coding-0.7.1-beta.1.zip`。使用 Python 3.10+ 标准库，无依赖安装、模型调用或全局安装。

安装完整的 `lean-coding/` 文件夹，调用 `$lean-coding`。安装位置、使用示例和更新方法见[仓库 README](../../README.md)。
